# 말랑메모

투명하고 말랑한 윈도우 데스크톱 메모 앱 (Electron)

## 설치
`MallangMemo-Setup-3.1.3.exe` 를 더블클릭하면 바로 설치되고 실행됩니다.
바탕화면과 시작 메뉴에 "말랑메모" 바로가기가 생겨요.

## 메모 데이터 위치
`%APPDATA%\MallangMemo\memo-data.json` (바로 직전 저장본은 `.bak`)
트레이 아이콘 메뉴 → "메모 저장 폴더 열기"로 열 수 있어요. 앱을 지워도 메모는 남아 있습니다.

## 휴지통과 백업
- 삭제한 메모는 휴지통에 7일간 보관 후 자동으로 영구 삭제돼요. 영구 삭제하면 저장 파일과 직전 저장본(.bak)을 0으로 덮어쓴 뒤 다시 저장해서 지운 내용이 파일에 남지 않아요.
- 꾸미기 탭 > 백업: 비밀번호(AES-256)로 잠근 .mallang 파일로 내보내고 가져올 수 있어요. 가져오기는 지금 메모에 추가만 해요.

## 직접 수정해서 다시 빌드하기
```
npm install
npm run fonts      # 글꼴 복사 (최초 1회)
npm start          # 개발 실행
npm run dist       # 설치 파일 만들기 (윈도우에서 실행 권장)
```
